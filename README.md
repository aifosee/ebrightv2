# Ebright Academy — Parent-Facing Landing Page

A modern, responsive marketing landing page for **Ebright Academy**, a kids' public
speaking academy aimed at Malaysian parents. Built as a single self-contained
`ebrightv2-aifosee-sms.html` (no build step, no dependencies) — just open it in a browser.

## Design

- Premium ed-tech look: deep navy background with baby-pink + white accents
- Bold typography, diagonal/geometric shapes, subtle gradients and glassmorphism
- Fully responsive for web and mobile

## Sections

1. **Hero** — what the academy does for your child
2. **Monthly calendar** — monthly showcase + festive Malaysian events (Raya, CNY, Deepavali, Merdeka)
3. **What we offer every month** — monthly showcase, parent feedback, referral program
4. **Parent reviews** — testimonials
5. **Referral program** — reward card

> All content uses mock data for demonstration.

## Run

Open `ebrightv2-aifosee-sms.html` in any modern browser.
